## 📌 Overview

**Glitchverse** is an innovative gaming experience created during the **Artificial Arcade Hackathon** organized by **Atharva University, Mumbai**. Built using modern web technologies, Glitchverse delivers a unique web-based arcade experience powered by dynamic AI interaction and real-time frontend execution.

🌐 **Live Application:** [glitchverse-7ob4.onrender.com](https://glitchverse-7ob4.onrender.com)

---

## ✨ Features

- **AI-Powered Arcade Gameplay:** Interactive and dynamic game interactions featuring **Autoplay**.
- **Responsive Web UI:** Built for smooth execution across desktop and mobile browsers.
- **Fast Local Development & Cloud Deployment:** Easy setup with Node.js and Render hosting integration.

---

## 🛠️ Tech Stack

- **Frontend / Runtime:** Node.js, JavaScript / TypeScript
- **Deployment Platform:** [Render](https://render.com)
